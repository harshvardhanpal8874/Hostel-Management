# Hostel Management System

## 📌 About the Project

Hostel Management System is a console-based Java application designed to manage student records and hostel room allocation. It provides a simple menu-driven interface for performing hostel management operations.

## ✨ Features

- Add and manage student records
- Update student information
- Remove student records
- Allocate rooms to students
- View room and student details
- Menu-driven console interface

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList and Collections
- Loops and Conditional Statements
- Switch Statements

## 📂 Project Structure

- `Menu.java` — Menu-driven program interface
- `main.java` — Application entry point
- `student.java` — Student-related operations and data
- `room.java` — Room management
- `service.java` — Hostel management operations

## ▶️ How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/harshvardhanpal18874/Hostel-Management.git
   ```

2. Open the project in IntelliJ IDEA, Eclipse, or another Java IDE.
3. Ensure that the JDK is installed and configured.
4. Run the class containing the `main()` method.
5. Follow the console menu to use the application.
